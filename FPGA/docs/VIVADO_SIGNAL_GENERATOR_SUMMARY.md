# Vivado 波形信号发生器项目说明

> 工程：`FPGA_xc7a35t`  
> 顶层：`DAC904_TOP`  
> 器件：Xilinx Artix-7 `xc7a35tfgg484-2`  
> 开发环境：Vivado 2022.2  
> 目标板卡：黑金 AX7A035B  
> 文档日期：2026-10-28

## 1. 项目概述

本项目将原 Quartus/Cyclone IV 波形发生器移植到 Xilinx Vivado，并在原有 DAC904 波形输出、频率计和板级接口基础上加入 STM32 SPI 控制。

系统由 STM32 发送 8 位命令字节，FPGA 完成命令解码、波形选择、频率字更新、自动扫频、软复位和频率计控制，最终通过 14 位并行接口驱动 DAC904。当前扫频功能已改为由 SPI 命令 `0111` 控制，不再使用 KEY4 按键。

项目的主要目标如下：

- 将 Altera 专用 PLL、ROM 和约束替换为 Vivado IP 与 Xilinx 约束。
- 保留原设计的正弦波、三角波、方波、DAC904 输出和频率计功能。
- 使用 STM32 软件 SPI 完成 FPGA 参数控制与链路回读。
- 增加 1 kHz 步长、1 s 更新一次的自动扫频功能。
- 完成板级引脚锁定、时序约束、仿真、综合、实现和 JTAG 下载。

## 2. 系统组成

系统信号链如下：

```text
板载 200MHz 差分时钟
        │
        ▼
 IBUFDS / BUFG → 4 分频 → 50MHz → MMCM → 165MHz
        │
        ├──────────────► SPI 从机与命令解码
        │                       │
        │                       ├─ 波形选择 sel[1:0]
        │                       ├─ 频率字 fre_k[31:0]
        │                       ├─ 频率计使能 meas_en
        │                       └─ 相位软复位 phase_rst
        │
        └──────────────► 32 位相位累加器 → 12 位 ROM 地址
                                │
                 ┌──────────────┼──────────────┐
                 ▼              ▼              ▼
              正弦 ROM       三角 ROM       方波逻辑
                 └──────────────┼──────────────┘
                                ▼
                          波形选择电路
                                │
                                ▼
                        14 位 DAC904 接口

TLV3501 比较器输出 → 同步/去抖 → 1 s 闸门频率计 → 频率指示
STM32 PA8/PA9/PA11/PA10 ↔ FPGA SCK/MOSI/NSS/MISO
```

主要模块及作用：

| 模块 | 作用 |
|---|---|
| `PLL_CLK` 与 `pll_165m` | 将 50 MHz 参考时钟倍频为 165 MHz 系统时钟 |
| `add_32bit` | 按频率字累加相位，取高 12 位作为 ROM 地址 |
| `ROM_Sin` / `rom_sin` | 存储 4096 点、14 位正弦波数据 |
| `ROM_Tri` / `rom_tri` | 存储 4096 点、14 位三角波数据 |
| `sel_wave` | 在正弦、三角和方波之间选择输出 |
| `spi` | 接收 STM32 的 Mode0、MSB-first、8 位 SPI 命令 |
| `cmd_con` | 解码命令，控制波形、频率、扫频、使能和软复位 |
| `simple_freq_meter` | 测量比较器输入频率，闸门时间约 1 s |
| `DAC904_TOP` | 顶层集成、时钟分配和 DAC/LED/SPI 接口 |

## 3. 已实现功能

### 3.1 波形生成

- 正弦波和三角波采用 4096 × 14 位 Block Memory ROM。
- 方波由相位累加器最高地址位生成，输出为 0 或 16383 两个电平。
- 频率控制采用 32 位相位累加字，输出频率近似为：

```text
f_out = fre_k × 165 MHz / 2^32
```

- `fre_k = 26031` 对应约 1 kHz。
- 输出数据为 14 位，通过 DAC904 转换为模拟波形。

### 3.2 SPI 从机

- 协议为 SPI Mode0：空闲 SCK 低电平，上升沿采样，MSB 先行，每帧 8 位。
- `SCK`、`MOSI`、`NSS` 输入经过 3 级同步后进入 165 MHz 时钟域。
- 帧结束由 `NSS` 上升沿识别，并产生一个时钟宽的 `data_valid` 脉冲。
- MISO 在片选有效时回显同步后的 MOSI，保持 STM32 端原有的 `g_rx == g_tx` 判据。
- 片选无效时 MISO 输出低电平。

### 3.3 SPI 命令

| 命令 | 十六进制 | 功能 |
|---|---:|---|
| `0001` | `0x01` | 频率增加一档，按当前频段自适应步进 |
| `0010` | `0x02` | 波形循环切换：正弦 → 三角 → 方波 → 正弦 |
| `0011` | `0x03` | 频率降低一档 |
| `0100` | `0x04` | 频率计使能开关 |
| `0101` | `0x05` | 频率固定增加 1 kHz |
| `0110` | `0x06` | 频率固定降低 1 kHz |
| `0111` | `0x07` | 从 1 kHz 启动或重新启动自动扫频 |
| `1000` | `0x08` | 软复位：1 kHz、正弦波、频率计开启、相位清零 |

其他命令码会被忽略，当前状态保持不变。

### 3.4 自动扫频

- 扫频由 SPI 命令 `0111` 启动。
- 每次收到 `0111` 都从 1 kHz 重新开始。
- 每 `165000000` 个 165 MHz 周期增加一次频率字，即每隔 1 s 增加 1 kHz。
- 扫频步长固定为 `26031`，对应约 1 kHz。
- 到达 100 MHz 后回卷到 1 kHz 并继续扫频。
- 手动频率命令 `0001`、`0011`、`0101`、`0110` 以及软复位 `1000` 会停止扫频。
- 波形切换和频率计开关不会中断正在运行的扫频。

在当前命令定义中，`0111` 用于启动或重新启动扫频；若需要停止并保持当前频率，可发送手动频率命令或软复位。

### 3.5 频率计与指示

- 比较器输入先进行同步和去抖，再进入约 1 s 的闸门计数。
- 频率计算公式为：

```text
frequency = signal_count × 165000000 / standard_clock_count
```

- 扩展板 LED1～LED3 分别指示正弦、三角和方波，低电平点亮。
- LED4 指示频率计使能。
- 核心板 LED 在测得频率不高于 1 MHz 时点亮。

## 4. 时钟、IP 与板级接口

### 4.1 时钟与 IP

板载 200 MHz 差分时钟从 `R4/T4` 输入，经 `IBUFDS/BUFG` 后四分频得到 50 MHz，再由 Clocking Wizard MMCM 产生 165 MHz 主时钟。

原 Quartus IP 与 Vivado IP 的替换关系如下：

| 原 Quartus IP | Vivado IP | 说明 |
|---|---|---|
| `altpll` | `clk_wiz` / MMCM | 50 MHz 输入，165 MHz 输出 |
| `altsyncram` 正弦 ROM | `blk_mem_gen` | 4096 × 14，单端口 ROM |
| `altsyncram` 三角 ROM | `blk_mem_gen` | 4096 × 14，单端口 ROM |

### 4.2 主要引脚

| 信号 | FPGA 引脚 | 电平标准 | 说明 |
|---|---|---|---|
| `sys_clk_p/n` | R4 / T4 | DIFF_SSTL15 | 200 MHz 板载差分时钟 |
| `SYS_RST` | F15 | LVCMOS33 + PULLUP | 低有效复位 |
| `SCK` | G21 | LVCMOS33 | STM32 PA8 |
| `MOSI` | G22 | LVCMOS33 | STM32 PA9 |
| `NSS` | C22 | LVCMOS33 | STM32 PA11 |
| `MISO` | B22 | LVCMOS33 | STM32 PA10 |
| `DAC_CLK` | A19 | LVCMOS33 | DAC 采样时钟 |
| `DAC_DATA[13:0]` | B20…A16 | LVCMOS33 | 14 位 DAC 数据 |
| `comparator_out` | F19 | LVCMOS33 | 频率计输入 |
| `led[3:0]` | L13/M13/K14/K13 | LVCMOS33 | 工作状态指示 |

## 5. 工程实现要点

- 主时序由 `top.xdc` 约束，200 MHz 输入时钟周期为 5 ns。
- 165 MHz 时钟由 MMCM 派生，不需要手工重复创建。
- SPI 和比较器输入属于异步端口，使用 `set_false_path`，模块内部通过同步器处理跨时钟域。
- 频率计除法组合路径采用多周期约束，避免低频测量的慢路径影响 165 MHz 主时序。
- 源文件使用 GBK 无 BOM 编码交付 Vivado；Markdown 报告使用 UTF-8。
- SPI 从机、命令解码和扫频状态机使用同一个 165 MHz 时钟域。

## 6. 验证状态

基础移植和 SPI 合并版本已完成以下验证：

- SPI 位回环和命令解码仿真通过。
- 顶层 PLL、三种波形、频率切换、频率计使能、软复位和 MISO 回环仿真通过。
- 综合与实现为 0 errors、0 critical warnings。
- 已生成并下载过 `DAC904_TOP.bit`。

2026-10-28 的源码已将自动扫频入口从 KEY4 改为 SPI `0111`。该次改动完成后，需要重新同步测试平台和约束文件，再对“SPI `0111` 扫频”版本执行最终仿真、综合和板级验证。

另外，LCD 上的“通信成功”表示 MISO 与 MOSI 的位回环一致，并不单独证明命令帧一定被 FPGA 解码。因此，最终验收应同时观察 SPI 返回状态、板载 LED 和 DAC 实际输出。
