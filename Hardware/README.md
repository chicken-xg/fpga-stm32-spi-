# 硬件资料说明（文本版）

本目录以文本形式记录系统硬件组成与在本项目中的角色，不存放原理图/数据手册文件。

系统整体由三部分组成：

```
STM32 控制部分（含 1.8 寸 TFT）
        │  SPI（主机 → 从机）
        ▼
黑金 FPGA 开发板（AX7A035B，承载波形发生器逻辑）
        │  14 位并行数据 + 165MHz 时钟
        ▼
高速 DAC904 模块（14 位 DAC，输出模拟波形）
```

## 1. 黑金 FPGA 开发板

| 项目 | 内容 |
| ---- | ---- |
| 开发板 | 黑金 AX7A035B |
| FPGA 芯片 | Xilinx Artix-7 XC7A35TFGG484-2（484 引脚 FBGA，速度等级 -2） |
| 系统时钟 | 板载 200MHz 差分时钟（SYS_CLK_P=R4 / SYS_CLK_N=T4，来自工程顶层注释） |
| 开发工具 | Vivado 2022.2 |

**在本项目中的角色**：承载波形发生器顶层 `DAC904_TOP`——

- 200MHz 差分时钟内部分频为 50MHz，经 PLL 生成 165MHz 采样时钟；
- 产生 14 位波形数据（正弦/三角/方波）驱动 DAC904，输出 DAC_CLK、PD 等控制信号；
- 内置 SPI 从机接口，接收 STM32 下发的波形选择与频率命令（取代原 4 按键方案）；
- 板载 LED 指示当前波形与频率计使能，BEEP 蜂鸣器输出；
- 频率计通过 DAC904 模块的 `comparator_out` 反馈信号测频。

> 板载其它外设资源（DDR、USB、以太网等）以开发板配套手册为准，本说明仅记录本项目实际用到的部分。

## 2. 高速 DAC904 模块

| 项目 | 内容 |
| ---- | ---- |
| 芯片 | TI DAC904 |
| 分辨率 | 14 位 |
| 最高采样率 | 165 MSPS |
| 接口 | 并行数据输入（14 位） |

**在本项目中的角色**：

- FPGA 输出 `DAC_DATA[13:0]`（14 位并行数据）、`DAC_CLK`（165MHz 采样时钟）和 `PD`（低功耗控制）；
- 输出电压转换公式（来自顶层注释）：`(16383 - DAC_DATA) × (6V / 16383)`，默认不启用输出放大/缩小，短路帽接 12；
- 模块输出经比较器（`comparator_out`）反馈回 FPGA，供频率计使用。

> 原资料目录保留 `DAC904原理图.pdf` 一份，未随本仓库复制。

## 3. STM32 部分的 1.8 寸 TFT 液晶显示屏

| 项目 | 内容 |
| ---- | ---- |
| 尺寸 | 1.8 英寸 |
| 接口 | SPI |
| 驱动芯片 | ST7735 |
| 分辨率 | 128 × 160 |

**在本项目中的角色**：属于 STM32 控制侧外设，由 `STM32/HARDWARE/LCD` 下的 ST7735 驱动程序通过软件 SPI 驱动，显示当前波形、频率、扫频状态与 FPGA 通信状态。

> v1.0 阶段归档的 STM32 固件为 HAL 库 SPI 通信测试程序，未包含本屏驱动；v2.0 最终固件已纳入完整 LCD 显示功能。
