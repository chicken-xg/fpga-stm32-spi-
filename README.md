# fpga-stm32-spi-

STM32 + FPGA 可控波形信号发生器：STM32 通过按键操作、1.8 寸 TFT 本地显示，经软件 SPI 向黑金 FPGA 开发板下发命令，由高速 DAC904 输出正弦波 / 三角波 / 方波。当前版本 **v2.0（最终版）**。

## 系统架构

```
STM32F103C8T6  ──软件 SPI──>  FPGA XC7A35T  ──14 位并行──>  DAC904(165MSPS)  ──>  波形输出
  按键 / ST7735 TFT 本地交互、波形与频率状态显示
```

## 目录说明

| 目录 | 说明 |
| ---- | ---- |
| `FPGA/` | Vivado 2022.2 波形发生器工程：RTL 源码、仿真、约束、IP、ROM 数据、比特流与开发文档 |
| `STM32/` | Keil MDK 固件：标准库、按键扫描、软件 SPI、ST7735 LCD 显示驱动 |
| `Hardware/` | 硬件组成文本说明（黑金 AX7A035B 开发板、DAC904 模块、1.8 寸 TFT） |

各部分原理、模块清单、引脚与重建方法见对应目录下的 `README.md`。

## 版本记录

- **v2.0（当前 main 分支，最终版）**：FPGA 新增 SPI `0x07` 自动扫频（1 kHz/s，1 kHz～100 MHz 循环）；STM32 更换为标准库最终固件，7 个按键控制、ST7735 LCD 实时显示波形 / 频率 / 扫频状态 / 通信状态。
- **v1.0**：初始版本，FPGA 完成基础波形输出与 SPI 命令接收，STM32 为 HAL 库 SPI 通信测试程序；该版本代码保存在 `v1.0` 标签与提交历史中。

两版本差异与升级说明见仓库 Releases 页面。
